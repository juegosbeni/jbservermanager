JBSM Installer

Descarga e instalación del sistema JBSM para Windows

Descargar JBSM_installer.bat

⚠ SOLO COMPATIBLE CON WINDOWS

📌 Cómo instalarlo

1. Haz clic en el botón de descarga
2. Se descargará el archivo JBSM_installer.bat
3. Abre la carpeta de descargas
4. Haz doble click en el archivo
5. Si Windows muestra advertencia, pulsa "Más información" → "Ejecutar igualmente"
6. Sigue las instrucciones del instalador

ℹ Información importante

• El instalador descarga automáticamente todos los archivos necesarios
• No cierres la ventana durante la instalación
• Se recomienda ejecutar como administrador
• Requiere conexión a Internet
